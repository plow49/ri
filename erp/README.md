# RI ERP 개발용 시제품

## 실행
Windows에 Python 3.12(설치 시 Tcl/Tk 포함)를 설치하고 `start-windows.cmd`를 실행합니다.
기본값은 실행 폴더의 `erp-local.db` SQLite 데이터베이스입니다. 별도 서버는 필요 없습니다.

Oracle 19c 이상 개발용 스키마를 권장합니다. 실행 전 `ERP_DATABASE_URL` 환경 변수를
`oracle+oracledb://USER:PASSWORD@HOST:1521/?service_name=SERVICE` 형식으로 안전하게 설정합니다.
특수문자는 URL 인코딩해야 합니다. 비밀번호를 소스나 Git에 저장하지 마세요.
실행 시 ERP_ 접두사의 테이블을 생성하므로 운영 스키마 대신 전용 개발 스키마를 사용합니다.
Golden7은 같은 Oracle 스키마에 연결하여 테이블을 조회하는 관리 도구입니다.
Oracle 서버 연결 및 Windows GUI 실행은 아직 검증하지 않았습니다.

## 검증 가능한 구매 흐름
1. 품목 등록: 자동 발주 기준 5, 발주 수량 20.
2. 품목 ID로 공급업체·수량 10·단가 100의 구매 요청을 등록합니다.
3. 구매 탭에서 요청을 선택하고 다음 단계를 실행합니다: 발주 → 입고 → 송장 → 지급.
4. 입고 시 재고 +10, 재고자산/미착송장부채 1,000원 전표가 생성됩니다.
5. 송장 시 미착송장부채/매입채무로 대체하고 지급 시 매입채무/현금 전표를 생성합니다.
6. 자재 5개 사용 시 이전 입고 이력의 공급업체·단가를 이용해 20개 내부 발주를 자동 생성합니다.
7. 미입고 요청·발주가 존재하면 중복 발주하지 않습니다. 실제 공급업체 전송은 하지 않습니다.

수량은 정수, 금액은 정수 원화입니다. 부분 입고, 반품, 세금, 환율, 지급 승인 및 취소는 미구현입니다.
자재 사용은 수량만 반영하며 원가 전표는 아직 생성하지 않습니다.
Oracle는 품목 행 잠금으로 동시 재고 변경을 직렬화합니다. SQLite 모드는 단일 사용자 개발용입니다.

## 구현 범위와 후속 개발
구매·재고·자동 내부 발주 및 단순 복식전표가 구현되어 있습니다.
CO, SD, PP, QM, HR 탭은 업무 기록 등록·조회만 제공합니다.
예산·원가 배부·손익 분석, 판매/출고/수금 연동, BOM/MRP/공정,
검사 판정/격리, 근태/급여/평가 계산, 재무제표는 아직 구현되지 않았습니다.
권한·로그인·감사 로그·백업·마이그레이션도 필요합니다. 운영용 완성 ERP가 아닙니다.
급여와 세무 계산은 적용 국가·회계정책·근무제도 확정 후 구현해야 합니다.

## 테스트
`python -m pip install -r requirements.txt`

`python -m unittest -v` (erp 디렉터리에서 실행)

Windows 배포용 exe는 Windows에서 PyInstaller를 설치한 후
`python -m PyInstaller --onefile --windowed --name RI-ERP --collect-all oracledb app.py`로 빌드할 수 있습니다.
해당 패키징 명령 및 생성 exe는 아직 검증하지 않았습니다.

## 추가 구현 (2026-11-03)
앞의 초기 구현 범위 중 SD/QM/HR는 다음으로 확장되었습니다.
- SD: 판매 주문 → 출고(재고 차감·매출채권/매출 전표) → 수금 전표.
  출고 시에도 자동 내부 발주를 검사합니다. 매출원가 전표는 미구현입니다.
- QM: 자재·공정·완제품 검사 수량/불량 수량 등록 및 유효성 검증.
  로트별 추적, 불량 재고 격리, 출고 차단은 아직 없습니다.
- HR: 사원 식별명·월별 세전 급여와 사용자가 확정한 공제액으로 실수령액 계산,
  급여비용/미지급급여 및 예수금 전표 생성, 동일 사원·월 중복 방지.
  법정 세금·보험료 자동 계산, 근태·인사·평가는 아직 없습니다.
- FI: 계정별 차대 잔액 조회. 정식 재무제표 및 결산은 미구현입니다.
CO/PP는 여전히 업무 기록만 지원합니다.

## Windows 로컬 배포 0.3
Oracle 검증은 요청에 따라 제외했습니다. 배포 ZIP에서는 `install-windows.cmd`로 설치하고
`run-windows.cmd`로 실행합니다. 이 실행기는 항상 SQLite를 선택합니다.
`requirements-local.txt`는 Oracle 드라이버를 설치하지 않습니다.
Python이 없으면 winget 설치를 시도하며, 설치 후 스크립트를 다시 실행해야 합니다.
바탕화면 바로가기를 생성하며 기존의 RI ERP 바로가기는 갱신합니다.
실제 Windows 실행 검증은 아직 수행하지 못했습니다.

## 디자인 업데이트 0.4
물품 상자 아이콘(PNG 및 다중 해상도 ICO), 맑은 고딕 우선 글꼴,
남색/청록 테마, 한글 표 제목, 교차 행 배경과 세로 스크롤을 적용했습니다.
설치 시 바탕화면 바로가기 아이콘도 갱신됩니다. CMD 파일 자체 아이콘은 변경되지 않습니다.
기존 사용자는 erp-local.db를 백업하고 새 ZIP을 별도 폴더에 설치한 후,
프로그램을 종료한 상태에서 기존 DB를 새 폴더로 복사하세요.
Windows 화면의 실제 렌더링은 미검증입니다.
