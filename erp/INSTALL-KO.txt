RI ERP 0.3 — Windows 로컬 설치 패키지

Oracle 서버나 Golden7 없이 SQLite로 실행합니다.
대상: Windows 10/11, 단일 사용자 개발용. 독립 실행 EXE는 아닙니다.

설치
1. ZIP을 문서 폴더 등의 쓰기 가능한 위치에 완전히 압축 해제하세요.
   ZIP 내부에서 바로 실행하지 마세요.
2. install-windows.cmd를 더블클릭하세요.
3. Python 3.12가 없으면 winget으로 설치합니다. 설치 후 안내에 따라
   창을 닫고 install-windows.cmd를 다시 실행하세요.
   winget이 없으면 python.org에서 Python 3.12를 직접 설치해야 합니다.
   Python Launcher와 Tcl/Tk 구성요소를 포함하세요.
4. 의존성 설치, 업무 테스트, Windows GUI 생성 검사가 진행됩니다.
5. 바탕화면의 RI ERP 또는 run-windows.cmd를 실행하세요.

최초 설치에는 인터넷 연결이 필요합니다. 설치 후 로컬 업무는 인터넷 없이 사용합니다.
바로가기는 압축 해제 폴더를 참조하므로 설치 후 폴더를 이동하지 마세요.
데이터는 프로그램 폴더의 erp-local.db에 보관됩니다.
업데이트·제거 전에 프로그램을 닫고 이 파일을 별도로 백업하세요.
삭제하려면 프로그램을 종료하고 해당 폴더와 바탕화면 바로가기를 삭제하세요.

검증 상태
Linux에서 업무 테스트 7건 통과. 실제 Windows에서 실행 검증하지는 못했습니다.
설치 스크립트는 사용자 Windows에서 같은 업무 테스트와 Tk GUI 생성 검사를 실행합니다.
전체 ERP 완성본은 아닙니다. 상세 기능과 미구현 범위는 README.md에 있습니다.
