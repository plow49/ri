삭제 기능 테스트 버전 — 정식 배포 아님

새 폴더에 압축 해제하여 실행하세요. 실제 업무 DB 대신 테스트 데이터를 사용하세요.
확인 순서: 물품 총수량 입력 → 반출/반입 기록 추가 → 하단 선택 기록 삭제 → 현재 수량 확인 → 상단 선택 물품 삭제.
삭제 확인 창에서 취소 시 데이터가 유지되는지도 확인하세요.
상단 물품 삭제는 기준 총수량과 해당 물품의 기록 전체를 삭제합니다. 하단 삭제는 기록 1건만 삭제합니다.

M_물품관리 Windows EXE

다운로드한 ZIP을 문서 폴더 등 쓰기 가능한 폴더에 압축 해제하고 물품관리.exe를 실행하세요.
EXE 자체에 M 아이콘을 포함했습니다. Python 설치나 CMD 실행이 필요 없습니다.
데이터는 EXE와 같은 폴더의 materials.db에 저장됩니다. EXE를 옮기면 DB도 함께 옮기세요.
이전 버전 데이터 사용: 프로그램을 모두 종료하고 materials.db를 백업한 뒤 EXE 옆에 복사하세요.
새 버전 EXE로 교체해도 기존 DB를 삭제하지 마세요. 여러 프로그램을 같은 DB에 동시에 실행하지 마세요.
이 빌드는 코드 서명되지 않았습니다. Windows에서 경고가 발생하면 내용을 확인하세요.
자동 검사는 GUI 생성·아이콘 로드·SQLite 처리를 확인하며, 모든 화면의 수동 검증은 아닙니다.
