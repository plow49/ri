M_물품관리 1.4.9

변경 사항
- 물품 종류와 반출·반입 기록 수를 상단 요약 카드로 이동
- 남색 헤더, 흰색 목록 영역, 추가·수정·삭제 버튼 디자인 정리
- 기존 반출처, 수량 계산, 삭제, 휠 스크롤, 업데이트 기능 유지

기존 프로그램의 업데이트 확인 버튼으로 설치할 수 있습니다.
처음 사용하는 경우 M-Materials.exe를 쓰기 가능한 폴더에 내려받아 실행하세요. Python 설치는 필요하지 않습니다.
데이터와 백업은 %LOCALAPPDATA%\M_Materials에 보관됩니다. 업데이트 전 이 폴더를 백업하면 안전합니다.
Windows EXE는 코드 서명되지 않았습니다. 이 릴리스는 공개 저장소 표준 실행기에서 빌드·실행 검증을 통과한 결과입니다.
UI-normal.png와 UI-small.png는 Windows에서 예시 데이터를 사용해 캡처한 화면입니다.
