# M_물품관리
기존 ERP와 별개인 단일 사용자용 물품 반출·반입 기록 프로그램입니다.

1. ZIP을 쓰기 가능한 별도 폴더에 압축 해제합니다.
2. install-windows.cmd를 실행합니다. Python 3.12가 없으면 설치 후 다시 실행합니다.
3. 바탕화면 물품관리 또는 물품관리.cmd를 실행합니다.

항목 추가 버튼으로 물품명, 양의 정수 수량, 반출/반입, 교체/신규, 날짜, 이름을 입력합니다.
행을 선택하고 수정 버튼을 누르거나 더블클릭하면 모든 입력값을 수정할 수 있습니다.
반출/반입과 사유는 행별 편집 창의 선택 목록에서 선택합니다. 표 안에서 직접 입력하지 않습니다.
날짜 기본값은 PC의 오늘 날짜이며 YYYY-MM-DD 형식으로 변경할 수 있습니다.
취소하면 저장하지 않습니다. 자료는 프로그램 폴더의 materials.db에 저장됩니다.
ERP의 erp-local.db와 독립적이며, 별도 외부 패키지나 Oracle 연결이 필요 없습니다.
물품별 기준 총수량과 반출/반입 이력을 이용해 현재 수량을 계산합니다. 회계 기능은 없습니다.

백업: 프로그램을 닫은 뒤 materials.db를 복사하세요. 업데이트 때 해당 파일을 보존하세요.
Windows 실행은 아직 미검증입니다. 설치 스크립트가 PC에서 데이터 테스트와 GUI 생성 검사를 실행합니다.

## 1.1 물품별 총수량
상단의 물품 총수량 입력 / 수정 버튼으로 물품별 기준 총수량을 입력하세요.
기준 총수량은 모든 저장된 기록을 반영하기 전의 수량입니다. 현재 실사 수량을 그대로 입력하면 과거 기록이 이중 반영될 수 있습니다.
현재 수량 = 기준 총수량 + 누적 반입 - 누적 반출. 동일한 물품명은 합산합니다.
기준 총수량 미입력 품목은 미입력으로 표시합니다. 음수 현재 수량은 빨간색으로 표시하며 과거 기록 입력을 차단하지 않습니다.
기존 기록은 보존하며 별도의 inventory 테이블을 자동 추가합니다. 수정 저장 시 합계를 재계산합니다.
업데이트 전 프로그램을 닫고 materials.db를 백업하세요. 새 폴더에서 사용할 경우 기존 materials.db를 새 폴더에 복사한 후 실행하세요.

## 1.2 실행 이름과 아이콘
실행 파일을 물품관리.cmd로 변경했습니다. 설치 시 바탕화면과 프로그램 폴더에 M 아이콘의 물품관리 바로가기를 만듭니다.
CMD 자체 아이콘은 Windows 기본 아이콘입니다. 사용자 지정 아이콘으로 실행하려면 생성된 물품관리 바로가기를 사용하세요. 프로그램 창에도 M 아이콘을 적용했습니다.
기존 M_물품관리 바로가기는 자동 삭제하지 않습니다. 새 바로가기를 확인한 뒤 필요하면 직접 삭제하세요. 폴더를 이동한 경우 설치 스크립트를 다시 실행해 바로가기를 갱신하세요.

## 1.3 M 아이콘
프로그램 창과 물품관리 바로가기의 아이콘을 남색 배경·청록색 M 이미지로 변경했습니다. 설치 스크립트를 다시 실행하면 바로가기가 갱신됩니다.
